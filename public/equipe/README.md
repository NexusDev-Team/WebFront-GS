# Fotos da equipe

Uma foto de cada integrante, em JPG, com estes nomes exatos. Já estão aqui, recortadas em quadrado
(256 x 256 px) centradas no rosto, para ficarem boas nos avatares redondos:

- `isac-nilton.jpg`
- `joao-benedito.jpg`
- `leonardo-formigari.jpg`
- `luis-fernando.jpg`

Para trocar uma foto: recorte quadrado com o rosto centralizado, 256 px ou mais, até uns 200 KB.
Se o arquivo não existir ou não carregar, a página Nexus Dev mostra um avatar com as iniciais.
